        What it is

        AgentForge is a local-first, model-agnostic development environment for turning AI-assisted work into explicit, reviewable engineering workflows. Plans, task contracts, capabilities, approvals, isolated worktrees, gates, CI observations, and audit records stay durable in the repository.

        What it is not

        It is not a sandbox, a security boundary, an autonomous merge bot, or a stable product contract. Agent output is untrusted work in progress. Use disposable projects, do not provide production secrets, and keep a human responsible for review, acceptance, integration, and retirement.

        Safe first run

        git clone https://github.com/cybercoretech/agentforge.git
cargo install --path crates/agentforge-cli --locked
forge init ./my-project
forge intake ./my-project
forge blueprint validate ./my-project

        Before launching an agent, inspect the task contract, verify its capabilities and approvals, confirm the executable path, and use a clean project with a known base commit. A successful process is evidence for review—not automatic acceptance.
